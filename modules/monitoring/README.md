# Monitoring Module

This module provisions enterprise-grade monitoring stack for Amazon EKS.

## Features

- Prometheus
- Grafana
- Alertmanager
- kube-state-metrics
- node-exporter
- CloudWatch Dashboards

## Security

- Kubernetes-native monitoring
- Persistent storage
- Secure ingress

## Observability

- Cluster Metrics
- Node Metrics
- Pod Metrics
- Kubernetes Metrics

## Enterprise Features

- Long-term retention
- Highly available stack
- Modular deployment

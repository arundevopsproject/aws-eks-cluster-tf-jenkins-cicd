This module provisions enterprise-grade GitOps platform using Argo CD.

## Features

- Argo CD
- Git Repository Integration
- AppProjects
- Applications
- ApplicationSets
- Automated Sync

## GitOps Capabilities

- Declarative Deployments
- Drift Detection
- Self Healing
- Automated Rollbacks

## Enterprise Features

- Multi-environment deployments
- Git-driven operations
- Kubernetes-native GitOps

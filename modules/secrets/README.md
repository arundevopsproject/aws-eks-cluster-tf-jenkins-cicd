# Secrets Module

This module provisions enterprise-grade secrets management platform for Amazon EKS.

## Features

- AWS Secrets Manager
- AWS SSM Parameter Store
- KMS Encryption
- External Secrets Operator
- Kubernetes Secret Sync

## Security Features

- KMS encryption
- Secret rotation ready
- IRSA integration
- Secure secret synchronization

## Enterprise Features

- Centralized secrets management
- Kubernetes-native integration
- Secure application secret delivery
